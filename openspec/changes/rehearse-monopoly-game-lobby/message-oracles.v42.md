an incomplete completion source inside this bool callback. Record the real bound
Send button's disabled state during the actual service call, optionally dispatch
a genuine second pointer click to observe duplicate prevention, then return the
configured true/false gate result. Do not change the button state in the fixture.

than claiming one yield awaits the command. Compare delivered messages and gate

cannot satisfy the later assertion. Reporting must exercise a real message

submission feedback. Direct Social.Report calls alone do not prove that UI path.

rendered/parsed TMP output. Do not require a particular raw storage encoding or
richText flag if another implementation renders the same required literal text.

characters. Unsupported emoji/image controls or message attachments must be
checked through actual interactive bindings/components and message-content roles,
not just English object names; ordinary avatars/backgrounds remain allowed.

that explicitly says the recipient is not a friend or private messages require
friendship. The positive word '好友' alone is insufficient. Keep successful bound
private delivery, loss of eligibility, readable history and failed draft coverage.

user overrides remain required. Record what the source actually proves.
