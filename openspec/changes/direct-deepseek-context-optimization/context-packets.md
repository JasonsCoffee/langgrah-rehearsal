Coder-owned narrative files are excluded before constructing the canonical
packet. A wrongly classified owned report is blocked before any selector/Judge
call and at the delivery boundary, with failed filtering checks and no payload.
The live builder obtains committed Git bytes, preserving CRLF and multiline
strings instead of inheriting native text-loader normalization. Dirty or stale
candidate source blocks review. Complete actual C# tests, implementation, trusted
rules, criteria and mechanical evidence remain mandatory. Frozen documents
themselves are preserved as provenance; their status claims are not Judge input.

The following design overview remains applicable; earlier pending-rollout notes
at the end are historical and are superseded by the final results above.

The optimizer is the trusted adapter, including exact packing, optional DeepSeek
selection and deterministic validation. Host means the Python execution program.
The cheap model selects references and cannot certify completeness or judge code.

Every invocation returns and persists `optimized_input`, `check_results`,
`decision`, canonical/optimized SHA256 identities, included/omitted sources,
metrics and fallback reasons. Each check names its verifier, status, evidence and
reason. The consumer validates hashes and code-verified checks before dispatch.
Model-reported checks cannot authorize delivery. Uncertain selector usage returns
`blocked` with no payload; invalid selection uses the original admissible input.

Canonical packets bind run, contract, current candidate, unit, review mode and
policy to exact sources, required IDs, criteria, spec, ownership and full mechanical
evidence. Current patched files and all supplied C# tests/dependencies are mandatory.
The live host deliberately retains all supplied C# rather than claiming precise
symbol closure. Unknown dependencies, partial classes and reflection promote
supplied scopes to full context. Missing evidence is a blocker, not authority to
guess or summarize it. Hashes alone never replace mandatory file bodies.

The deterministic packer deduplicates exact bodies with provenance references;
it preserves literal source bytes and distinct diagnostics/test relationships.
Only supporting acceptance notes are optional in the live builder. Retained old
proposals, worker reasons, private reasoning and configuration are not review
sources. Required coding rules remain. The selector can request exact UTF-8 spans
of optional items; unknown IDs, changed hashes, invalid boundaries, repeated or
overlapping spans, verdicts and policy/check claims fail closed.

The selector runs only for qualified classes and sufficiently large, optional-rich
input. Its calls are separately identified and charged to the same ledger. Exact
plan cache keys include canonical and policy identity. Unknown paid intents are
never replayed. Judge can request one exact-context expansion, then canonical
fallback, with three calls maximum; a constrained budget allows canonical-only
review or blocks dispatch. Each expansion has a fresh call ID. Final native JSON
schemas are unchanged. The compact Architect index preserves exact unresolved
classifications, explanations and original artifact references.

Raw canonical, result and compact checks artifacts live in trusted external
`context-packets/<canonical-hash>/`; verdicts and handoffs have separate identities.
Reports label UTF-8 conservative estimates, actual selector usage, cache reuse,
latency and fallback reasons. `context_cost_report.py` includes selector and
expansion overhead. No dated dollar price is activated: the Codex subscription
marginal dollar rate is unknown, so no verified cash-saving claim is made.

The small paid protocol corpus qualified four packet classes, not arbitrary
semantic omissions or real lobby correctness. Production packets may retain much
more mandatory source and therefore achieve substantially less reduction. The
scheduled live audit and first-ten-review observation remain activation follow-up.
